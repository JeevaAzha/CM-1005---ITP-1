# 🎮 CM1005 (ITP1) – Side-Scrolling Platformer Game

## 📖 Overview
This is a **2D side-scrolling platformer game** developed as part of the **CM1005 / ITP1 coursework**.  
The game challenges players to navigate obstacles, avoid enemies, and collect items while progressing through the level.  
It demonstrates fundamental game development concepts such as physics, collision detection, animation, and event-driven programming.

---

## ⚙️ Tech Stack
- **Language:** JavaScript  
- **Libraries:** [p5.js](https://p5js.org/), [p5.sound](https://p5js.org/reference/#/libraries/p5.sound)  
- **Assets:** Custom sprites and sound effects (`/assets` folder)  

---

## 🚀 Features
- 🎮 **Player Controls** – move, jump, interact with the world  
- 🪵 **Platforms & Collision** – stable physics-based movement  
- 👾 **Enemies & Hazards** – avoid falling or colliding with enemies  
- 💎 **Collectibles** – items that trigger sound effects when picked up  
- 🎶 **Sound & Music** – background soundtrack and interaction sounds  
- 🚀 **Win Condition** – reach the rocket endpoint to complete the level  
- ✨ **Particle Effects** – visual feedback for actions and events
